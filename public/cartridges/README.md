# Cartridge assets

The active model is the Famicom cartridge used by mamuso.dev, copied unchanged from its public repository at the user's request. See `models/SOURCE.md` for its exact source, revision and undeclared license status. No reference label artwork is included. Draco decoding uses locally hosted WASM, without a runtime CDN.

`src/cartridge/config.ts` selects the GLB, its orientation and the label node. The loader centers it, normalizes the width to 2.4 units, tints only shell materials, adds local green circuit-board artwork and metallic gold contacts to the original PCB meshes, and maps each local label onto the artwork primitive. The overlapping paper primitive is suppressed. The original procedural Game Boy shell remains in `src/cartridge/model.ts`; clear `cartridgeModel.url` to restore it.

Each entry also defines its shell finish. Stadia, Gmail and Blizzard use strong physical transmission; Search uses a subtler transmission with colored absorption, rather than lowering opacity; their labels stay opaque. Early work uses opaque matte charcoal plastic. Transmissive shells do not cast an opaque silhouette shadow, while their internal PCB still can.

The five active `labels/*-label.svg` files are self-contained editable vector stickers at 1260×600, matching the inspected artwork primitive’s 2.003×0.954 world-unit aspect and full 0–1 UV range. Each uses an original layout; selected labels include subtle static print grain. The flat print material preserves the authored ink colors/contrast instead of adding the shell’s studio glare; physical lighting and transmission remain on the housing. Blizzard and Search embed the existing local Blizzard wordmark and gradient Google G. The Blizzard drawing inherits even-odd filling to preserve its letter openings. Gmail uses its official vector wordmark once, with a single Chat subtitle and two red inbox-inspired metadata rows for role, internship, period and SF; Stadia uses its actual symbol and vector wordmark on an original arcade instruction plate with brushed metal, fasteners and a controls diagram. Logo and wordmark sources, revisions and collection-specific license details are recorded in `/models/BRAND-SOURCES.md`. Other motifs are original vector drawings. Search uses the gradient G, layered warm Material-style search geometry, Senior Product Designer, 2022–Now and SFO. Its typography and rounded tonal surfaces reference Google’s official Material Design source. Every label prints each visible fact once; field headings and redundant logo/name, location and period repeats are removed. No mamuso sticker art is used. The old `*-tonal.svg` panels and earlier Game Boy artwork remain unused, preserved assets.
