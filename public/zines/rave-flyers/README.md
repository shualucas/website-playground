# Flyer originals

These five JPEG files are the user's supplied designs, copied without re-encoding or retouching, in upload order: Wavform, Metronome, Ghosts ’n’ Stuff, Jornada Coffee Pop-up, and Kiteclub.fm Picnic.

The active `/after-hours/` zine uses 1110×1280 page textures and physical pages with the same aspect ratio. Three originals fit edge to edge. The narrower Jornada flyer is centered at its original aspect with matching green extensions; Picnic receives matching pale-pink extensions above and below. Background grain is drawn only behind the original images. All lettering and artwork remain intact, without cropping or nonuniform scaling. Each flyer occupies one interior page, followed by an unprinted inside-back page; existing covers are retained.

The fitting logic and page order live in `src/after-hours/flyers.js`. The archived `/zine/` portfolio retains its original page dimensions and content.
