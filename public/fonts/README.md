The licensed Quincy CF Regular Italic font file is not supplied in this repository.
Add the licensed WOFF2 file here, then set `quincyFontUrl` in `src/content/typography.ts`.
The bundled Cormorant Garamond Regular Italic is used until Quincy CF is supplied.

DM Sans, Staatliches, and Roboto Mono are self-hosted Google Fonts, licensed under SIL OFL 1.1. Their license notices are included alongside this file. The downloadable résumé preserves the typography embedded in the user’s original PDF.

The favicon uses an outlined J from Bagel Fat One, licensed under SIL OFL 1.1. Its license notice is included here; no font download is needed to render the icon.
